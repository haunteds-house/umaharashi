# Racecourse themes

Eleven original palettes cover all ten JRA racecourses plus Okinawa. Tokyo is
the default. These are inspired palettes, not official venue colors or logos.
Racecourse list: https://japanracing.jp/en/racing/go_racing/jra_racecourses/

The workspace uses a colored canvas, with lighter raised panels in Light and
separate dark surfaces in Dark. Okinawa uses a sunny sand canvas and teal accents
in Light. System/Light/Dark remains a separate setting for every palette.

Existing choices migrate: Original → Tokyo; Reef → Okinawa; Gusuku → Kyoto;
Yanbaru → Sapporo. Saved collections and appearance mode are preserved.
The old decorative frieze is replaced by a slim racing-rail color band.
The logo is an original line-art roof over a cross-braced stable gate.
